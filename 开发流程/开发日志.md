### 问题与解决
- **Python 3.8 类型注解兼容**: 添加 `from __future__ import annotations` 解决 `list[tuple]` 语法不兼容
- **端口 8000 多进程占用**: `pkill -f "python"` 不彻底导致旧进程残留，需 `taskkill /F /IM python.exe`
- **要素池数据质量问题**: 随机选部位导致"双脚转头"等不合理组合 → 添加动作-部位语义匹配规则修复
- **Ollama 未安装**: 本地环境无 Ollama → 替换为硅基流动（SiliconFlow）API，Qwen3-8B 永久免费
- **httpx 异步超时**: API 调用需 20-60s，httpx AsyncClient 偶发超时 → 超时增至 90s + 减少重试至 1 次 + 要素池兜底
