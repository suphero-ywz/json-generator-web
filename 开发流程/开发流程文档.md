## 一、项目概述

### 1.1 项目目标

开发一个 Web 应用，用户通过网页界面选取动作类别、输入权重和条数，一键或批量生成符合规范的动作数据集 JSON 文件。每次生成的 JSON 文件包含真实不同的动作，不重复。

### 1.2 核心需求

| 编号 | 需求 | 说明 |
|------|------|------|
| R1 | 类别多选 | 以复选框形式勾选要生成的动作类别 |
| R2 | 权重分配 | 为每个选中类别输入权重数值，系统自动换算实际条数 |
| R3 | 不重复生成 | 本地 LLM 实时创造新动作 + 要素池兜底，保证每个动作真实不同 |
| R4 | 历史记录 | 无账号体系，记录所有历史生成（仅存元数据），可查看和重新下载 |
| R5 | 预览功能 | 生成后在网页表格中预览数据，确认后再下载 |
| R6 | JSON 导入 | 支持导入已有 JSON 文件，导入的 query 自动进入去重池 |
| R7 | 批量生成 | 选择类别、权重、单文件条数后，批量生成多个 JSON 文件（上限 50 个） |
| R8 | 本地部署 | 先在本地跑通，后续部署到服务器 |

### 1.3 约束与限制

| 约束项 | 值 |
|--------|-----|
| 每次生成最大条数 | 5000 条 |
| 批量生成最大文件数 | 50 个 |
| 占比计算方式 | 用户输入权重（正整数），系统自动按权重比例分配条数 |
| 预览编辑 | 不支持单条编辑，预览只读 |
| 历史存储 | 仅存元数据，不存完整 JSON |
| LLM 依赖 | 可选 — 安装 Ollama 启用全新动作生成，未安装自动降级为要素池模式 |

## 三、核心生成策略：LLM 优先 + 要素池兜底

### 3.1 双模式架构

```
用户点击"生成"
      │
      ▼
┌─────────────┐
│  检测 Ollama │
│  是否可用    │
└─────┬───────┘
      │
  ┌───┴───┐
  │       │
  ▼       ▼
可用     不可用
  │       │
  ▼       ▼
┌─────┐ ┌────────┐
│LLM  │ │要素池   │
│模式 │ │模式     │
└──┬──┘ └───┬────┘
   │         │
   ▼         ▼
┌──────────────────┐
│  格式校验 + 去重   │
│  (写入 query_pool) │
└──────────────────┘
```

### 3.2 LLM 模式（主力）

**模型**: Ollama + qwen3:4b（约 2.5GB，中文能力强）

**调用方式**:
```python
# POST http://localhost:11434/api/generate
{
  "model": "qwen3:4b",
  "prompt": "<构造的 prompt>",
  "stream": False,
  "options": {"temperature": 0.9, "top_p": 0.95}
}
```

**一次请求生成一条动作数据**（确保每条都不同）。批量时循环调用，每次带不同的随机种子参数。

**Prompt 模板**:
```
你是一个数字人动作设计师，正在为光学动作捕捉数据采集工作服务。采集的动作数据将用于机器人训练，因此生成的动作应具备机器人运动学的典型特征：动作轨迹清晰、关节角度明确、起止分明、无拖泥带水的过渡。请创造一个全新的、独特的「{类别名称}」类别动作。

【要素要求】
- 身体部位从以下选取一个：{该类别可用部位列表}
- 动作方式必须是该类别下的合理动作
- 动作必须是人类可以完成的，物理上真实可行
- 不要与以下已有动作重复：{最近该类别已用的 5 个 query}

【严格约束 — 必须遵守，违反任何一条都是不合格输出】

1. 数量约束：
   - 动作重复次数不超过 3 次（如 "击掌3次" 合法，"击掌4次" 非法）
   - 行走/跑步/后退/侧移类步数不超过 5 步
   - 爬行类步数不超过 6 步
   - 舞蹈类时长 3-5 秒

2. 身体部位合法性约束（按类别）：
{此类别的部位约束表}

3. 物理可行性约束：
   - 禁止悬浮、飞行、穿墙、瞬移等违反物理定律的动作
   - 禁止同时执行矛盾动作（如 "一边向前走一边向后退"）
   - 禁止使用不存在的身体部位（如翅膀、尾巴、第三只手）
   - 禁止单部位同时向两个方向运动（如 "右手同时向左和向右挥"）
   - 禁止头部或上半身执行踢、踩、跳等下肢动作
   - 禁止双脚或双腿执行握、抓、指等手部动作
   - 单脚站立时，另一只脚可以抬起但不能同时做踩地动作

4. 安全与伦理约束：
   - 禁止自残类动作（撞墙、自打耳光等）
   - 禁止危险动作（高空跳跃、后空翻无保护落地等，特技类别除外）
   - 禁止攻击性动作（打人、踢人、掐脖子等，互动类别的碰拳/击掌除外）
   - 特技类别允许翻滚、倒立、劈叉，但禁止高风险动作（后空翻三周、高空坠落等）

5. 情绪-动作一致性：
   - [开心][活泼][兴奋] 不能配"缓慢""沉重"的动作
   - [疲惫][困倦] 不能配"快速""爆发"的动作
   - [严肃][郑重] 不能配"搞怪""滑稽"的动作
   - 情绪和速度必须协调：[爆发] 必须配快速，[优雅] 必须配慢速或标准

6. is_head 判定：
   - 仅涉及头部（歪头、点头、摇头、仰头、低头、转头）且不涉及身体其他部位 → TRUE
   - 涉及头部以外的任何身体部位 → FALSE

输出严格按以下 JSON 格式，不要输出任何其他内容：
{
  "query": "用户口语指令（10字以内）",
  "text": "详细动作描述（包含身体部位、幅度、速度、动作内容，以'最后回到站立姿态'结尾）",
  "motion_description": "[情绪]，身体部位，幅度，速度，动作名称+次数",
  "voice_feedback": "角色执行动作后的语音反馈（轻松口语化，15字以内）"
}

motion_description 格式规则：
- [情绪] 从以下选一：{类别适用的情绪列表}
- 身体部位：从该类别可用部位中选取
- 幅度：大幅 / 小幅 / 标准
- 速度：快速 / 慢速 / 标准
- 动作名称+次数：动作名称+数字+次，次数不超过3次，步数不超过5步
- 用中文逗号「，」分隔各字段
```

**温度参数**: 设为 0.9（高创造性），确保每次输出不同。

### 3.3 要素池模式（兜底）

当 Ollama 不可用时，使用要素池组合生成。虽然创造力不如 LLM，但通过足够大的要素池（来源：模板 + merged_deduplicated.json 3738 条数据提取），可以在相当长的使用周期内不重复。

## 四、AI 生成约束规则（LLM 护栏）

以下规则在 Prompt 工程 + 代码校验中双重执行。Prompt 中嵌入规则用于"预防"，validator.py 中代码校验用于"拦截"。

### 4.1 数量约束

| 约束项 | 规则 | 适用范围 |
|--------|------|----------|
| 动作重复次数 | ≤ 3 次 | 所有类别 |
| 行走步数 | ≤ 5 步 | 行走、跑步、后退、侧移 |
| 爬行步数 | ≤ 6 步 | 爬行 |
| 舞蹈时长 | 3-5 秒 | 舞蹈 |
| 踏步次数 | ≤ 4 次 | 踏步 |
| 跳跃次数 | ≤ 3 次 | 跳跃 |

### 4.2 身体部位 — 动作类型合法性映射

每个身体部位只能执行特定类型的动作，不能越界：

| 部位 | 可执行的动作类型 | 禁止的动作类型 |
|------|-----------------|---------------|
| 头部 | 点头、摇头、歪头、仰头、低头、转头（仅角度变化） | 踢、踩、跳、跑、打、指、握、抓 |
| 右手/左手 | 挥、拍、打、握、抓、指、比、举、推、拉、扔、弹、按、摸、写、画、擦、捏、摆手、击掌、碰拳、握手、飞吻、竖大拇指 | 踢、踩、跳、跑、站 |
| 双手/双臂 | 抱、举、推、拉、摆、挥、交叉、合十、击掌、拥抱、搬、托、捧 | 踢、踩、跳、跑 |
| 双脚/双腿 | 走、跑、跳、踢、踩、踏、蹲、站、跪、跨、蹦 | 握、抓、指、写、画、比心 |
| 左脚/右脚 | 抬、踢、踩、踏、跨、跺 | 握、抓、指、挥手 |
| 全身 | 所有类别动作（跳跃、舞蹈、特技、爬行等需全身协调） | — |
| 手指/指尖 | 比心、打手势、OK手势、V字、竖大拇指、指方向 | 踢、踩、跳、走 |
| 腰部 | 扭转、侧弯、前倾、后仰 | 踢、踩、走、跳 |
| 肩膀/右肩/左肩 | 耸肩、转动、抖动 | 踢、踩、抓、握 |
| 膝盖/右膝/左膝 | 弯曲、跪地、下蹲 | 挥、打、抓、握 |

### 4.3 各类别部位-动作约束速查表

LLM Prompt 中根据当前类别动态注入对应的约束：

#### 站立
```
允许部位: 全身, 头部, 双脚, 双手, 右手, 左手
禁止: 双脚离开地面（跳跃）、行走、跑步
头部可做: 歪头、仰头、低头、转头、点头、摇头
手部可做: 叉腰、抱胸、背手、贴裤缝、举过头顶
```

#### 行走 / 跑步
```
允许部位: 双脚, 双腿, 全身
禁止: 手部做复杂精细动作（不能在跑步时写字、画画）
步数限制: 行走 ≤5步, 跑步 ≤5步
跑步时双手可自然摆臂
```

#### 跳跃
```
允许部位: 双脚, 双腿, 全身, 左脚, 右脚
必须: 双脚或单脚离开地面
次数 ≤3 次
禁止: 跳跃同时做精细手部动作
```

#### 下蹲
```
允许部位: 双腿, 全身, 膝盖
动作: 深蹲、半蹲、马步、弓步、蹲下捡物
禁止: 下蹲时跳跃、下蹲时跑动
```

#### 特技
```
允许部位: 全身, 双手, 双脚, 双腿
允许: 后空翻、侧手翻、倒立、前滚翻、劈叉、单手俯卧撑
禁止: 后空翻三周、高空坠落、无保护头部着地、超出人类极限的动作
必须: 动作完成后回到站立姿态
```

#### 舞蹈
```
允许部位: 全身, 双脚, 腰部, 双手, 双臂
时长: 3-5 秒
禁止: 腾空超过1秒、违反关节活动范围的动作（如膝盖反弯）
```

#### 爬行
```
允许部位: 双手, 双脚, 膝盖, 全身, 手肘
步数 ≤6 步
禁止: 爬行时手部做精细动作
```

#### 单膝跪地
```
允许部位: 右膝, 左膝, 全身, 右手, 双手
必须: 单膝触地（不能双膝同时跪，除非特技/舞蹈类别）
允许: 求婚跪、行礼跪、骑士受封跪、跪姿射击
禁止: 跪着跳跃、跪着跑动
```

#### 互动
```
允许部位: 右手, 左手, 双手, 双臂, 全身, 头部, 手指, 右肩, 左肩
允许动作: 击掌、握手、碰拳、比心、挥手、飞吻、鞠躬、鼓掌、抱拳、敬礼、竖大拇指、OK手势、比V
禁止: 攻击性动作（打、踢、推倒）
鞠躬角度: 15度（点头致意）~90度（深鞠躬）
```

#### 挪动物品
```
允许部位: 双手, 右手, 左手, 双臂, 全身
允许: 搬、推、拉、拎、端、挂、抬
禁止: 抛、扔、摔、砸物品
物品: 箱子、推车、花瓶、行李箱、画框、袋子、桌子
```

#### 后退
```
允许部位: 双脚, 全身, 双腿
步数 ≤3 步
禁止: 后退时跳跃、后退时跑步
```

#### 侧移
```
允许部位: 双脚, 双腿, 全身, 左脚, 右脚
步数 ≤3 步
禁止: 侧移时跳跃
```

#### 踏步
```
允许部位: 双脚, 双腿, 左脚, 右脚, 全身
次数 ≤4 次
禁止: 踏步变成跳跃（脚不能同时离地）
```

#### 上肢动作(比心)
```
允许部位: 双手, 右手, 左手, 手指, 双臂, 指尖
允许: 头顶比心、手指比心、脸颊比心、爱心发射、背后比心、胸前比心
禁止: 比心同时做下肢复杂动作（可以站立不动或简单走位）
```

#### 其他
```
允许部位: 右手, 左手, 双手, 头部, 全身, 手指
允许: 喝水、打哈欠、擦汗、推眼镜、揉眼睛、戴耳机、伸懒腰、看手表、扇风、打电话
禁止: 包含其他15个类别的动作
```

### 4.4 物理可行性通用约束

| 约束 | 说明 | 示例 |
|------|------|------|
| 无悬浮 | 动作必须有支撑点 | ❌ "在空中悬浮转一圈" |
| 无瞬移 | 位置变化需经过中间过程 | ❌ "瞬间出现在三步之外" |
| 无矛盾 | 一个部位不能同时做两个方向的动作 | ❌ "右手同时向左又向右挥" |
| 关节限制 | 不能违反人体关节活动范围 | ❌ "手臂向后弯折90度" |
| 单脚平衡 | 单脚站立时，另一只脚可以抬起但不能同时踩地 | ❌ "左脚站立右脚同时跺地" |
| 手部做上肢动作时 | 下肢可以简单配合（站立、走1-2步），但下肢不能同时做复杂动作 | ❌ "一边比心一边高抬腿跑" |
| 动作有始终 | text 必须以"最后回到站立姿态"结尾 | ✅ "……，最后回到站立姿态" |

### 4.5 安全与伦理约束

| 约束 | 说明 |
|------|------|
| 禁止自残 | 不能有撞墙、自扇耳光、自掐等 |
| 禁止危险 | 不能有跳楼、高空坠落、头部猛撞等（特技中的前滚翻、倒立可接受） |
| 禁止攻击 | 不能有打人、踢人、掐脖等（互动类的击掌、碰拳可接受） |
| 禁止武器 | 动作中不能涉及刀、枪、棍棒等武器（特技中的棍术、剑术可接受，但需标注） |

### 4.6 情绪-动作一致性

| 情绪 | 须配速度 | 不能配的动作类型 |
|------|----------|-----------------|
| [爆发] | 快速 | 慢速、小幅、静立 |
| [优雅] | 慢速或标准 | 快速、跺脚、蹦跳 |
| [疲惫][困倦] | 慢速 | 快速、爆发、跳跃 |
| [开心][兴奋][活泼] | 标准或快速 | 沉重、缓慢（除非刻意反差） |
| [严肃][郑重][正式] | 标准或慢速 | 搞怪、滑稽、大幅度的随意动作 |
| [惊吓] | 快速 | 慢速 |

## 五、LLM 生成新关键词自学习机制

### 5.1 目的

LLM 生成的动作名称、身体部位组合、情绪词汇可能超出初始要素池。系统需要自动识别这些新关键词，经验证后写入要素池，实现持续自我扩展。

### 5.2 提取流程

```
LLM 生成一条动作数据
      │
      ▼
validator 校验通过
      │
      ▼
┌─────────────────────┐
│ 关键词提取器          │
│ extract_keywords()   │
└──────────┬──────────┘
           │
    从 motion_description 中提取：
      - 情绪（括号内文本）
      - 身体部位（第2字段）
      - 幅度（第3字段）
      - 速度（第4字段）
      - 动作名称（第5字段，去掉次数）
    从 text 中提取：
      - 动作动词
      - 新身体部位描述
           │
           ▼
┌─────────────────────┐
│ 与要素池对比          │
│ 是否为新关键词？      │
└──────────┬──────────┘
      ┌────┴────┐
      │         │
     新        已有
      │         │
      ▼         ▼
  写入要素池    跳过
  + 打标"LLM生成"
```

### 5.3 写入前校验

新关键词在写入要素池前须通过以下检查：

| 检查项 | 规则 |
|--------|------|
| 长度 | 2-20 字符 |
| 语言 | 纯中文（不含英文、数字、特殊符号） |
| 已存在 | 不在当前要素池中 |
| 非敏感词 | 不含政治、色情、暴力等敏感词汇 |
| 物理可行 | 对应类别可用（手动标注 category 匹配） |

### 5.4 人工审核标记

自动添加到要素池的关键词带有 `source: "llm_generated"` 标记和 `reviewed: false` 标记。前端可展示一个"新关键词审核"面板，供用户手动确认或移除。

### 5.5 示例

```
LLM 生成:
  motion_description: "[俏皮]，右手食指，小幅，快速，勾鼻尖1次"

提取:
  情绪: [俏皮] → 要素池中没有 → 写入情绪池
  动作: 勾鼻尖 → 要素池中没有 → 写入互动类别动作池
  部位: 右手食指 → 要素池中没有 → 写入身体部位池

3个新关键词自动入库，下次生成时可供选择和引用。
```

```
      ▼

      ▼
┌─────────────┐  不通过 → 退回 LLM 重试（最多3次）
│ 内容合法性   │           → 仍不通过 → 降级要素池
└─────┬───────┘
      │ 通过
      ▼
┌─────────────┐  重复 → 退回 LLM 重试（最多3次）
│ 去重校验     │        → 仍重复 → 降级要素池
└─────┬───────┘
      │ 通过
      ▼
  入库 + 触发关键词自学习
```

### 10.2 格式校验

| 校验项 | 规则 | 不通过示例 |
|--------|------|-----------|
| query 非空 | 长度 2-50 字符 | `""` 、`"来"` |
| text 结尾 | 必须包含"回到站立姿态" | `"...动作完毕"` |
| motion_description 字段数 | 按「，」分割后须为 5 个字段 | `"[开心]，右手，快速，击掌1次"`（少1字段） |
| 情绪格式 | 字段1 必须以 `[` 开头、`]` 结尾 | `"开心"，右手，..."` |
| 次数格式 | 字段5 须匹配 `动作名+数字+次` | `"击掌"`（无次数） |
| 幅度取值 | 字段3 须为：大幅/小幅/标准 | `"中等幅度"` |
| 速度取值 | 字段4 须为：快速/慢速/标准 | `"中速"` |
| is_head 合法 | 须为 TRUE/FALSE | `"yes"`、`1` |

### 10.3 内容合法性校验（AI 护栏落地）

| # | 校验项 | 规则 | 检测方式 |
|---|--------|------|----------|
| 1 | 次数上限 | 动作重复 ≤3 次 | 正则提取字段5中的数字，≤3 |
| 2 | 步数上限 | 行走/跑步/后退/侧移类步数 ≤5 步 | 类别判断 + 正则提取数字 |
| 3 | 爬行步数 | 爬行类步数 ≤6 步 | 类别判断 |
| 4 | 部位禁止越界 | 头部不能做踢/踩/跳/跑/打/指/握/抓 | text 中包含"头部"且包含禁止动词 → 拦截 |
| 5 | 下肢禁止越界 | 脚/腿不能做握/抓/指/比心/写/画 | text 中包含"脚/腿"且包含禁止动词 → 拦截 |
| 6 | 无悬浮 | text 不含"悬浮""飞行""飘""腾空超过" | 关键词匹配 |
| 7 | 无瞬移 | text 不含"瞬间""瞬移""闪现" | 关键词匹配 |
| 8 | 无自残 | text 不含"撞墙""自打""自扇""自掐" | 关键词匹配 |
| 9 | 无攻击 | 互动类不含"打人""踢人""掐脖子" | 关键词匹配 |
| 10 | 情绪速度一致 | [爆发]必须配快速，[优雅]必须配慢速或标准，[疲惫]必须配慢速 | 字段1和字段4交叉校验 |
| 11 | 无矛盾 | text 不含"同时向左又向右""同时向前又向后"等矛盾短语 | 关键词 + 正则 |
| 12 | 关节合法 | text 不含"反弯""反向弯折""逆关节" | 关键词匹配 |
| 13 | 不安全特技 | 特技类不含"三周""高空坠落""头部着地" | 类别判断 + 关键词 |
| 14 | 比心时脚不离地 | 上肢动作(比心)类 text 不含"跳""蹦""跑" | 类别判断 + 关键词 |
| 15 | 脚不离地 | 站立类 text 不含"跳起""双脚离地" | 类别判断 + 关键词 |

### 10.4 去重校验

| 校验项 | 规则 |
|--------|------|
| query 去重 | 查询 query_pool 表，query 不能已存在 |
| 同批次去重 | 同一生成批次内，所有 query 互不重复 |
| 批量跨文件去重 | 批量模式下，文件 N 的 query 不能与文件 1..N-1 的重复 |

### 10.5 校验失败处理

```
第1次校验失败 → 返回具体错误原因给 LLM，重新生成
第2次校验失败 → 返回具体错误原因 + 更严格的约束提示，重新生成
第3次校验失败 → 放弃 LLM，降级为要素池生成该条
要素池也失败 → 返回错误给前端："无法为类别「XX」生成更多不重复动作"
```
